## Tech Stack
- React
- Vite
- JavaScript (JSX)
- CSS

## Getting Started
1. Clone the repo
   git clone https://github.com/vedeshwarikumar/first-react.git
2. Go into the folder
   cd first-react
3. Install dependencies
   npm install
4. Start the app
   npm run dev

The app runs at http://localhost:5173
